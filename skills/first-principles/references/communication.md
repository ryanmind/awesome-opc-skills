# Communication Closure

Read this file only for communication tasks.

Treat the underlying decision as fixed unless the available evidence makes its core claim unsupported or contradictory. In that case, run decision closure before communication closure.

## Derive The Message

1. State the audience, intended decision or behavior, and non-negotiable claim.
2. Keep only facts and reasoning necessary to support that claim.
3. Remove background, caveats, and status narration that do not change the audience's decision.
4. Distinguish verified facts from assumptions or recommendations.
5. End with the requested decision, action, or response when one is needed.

Do not manufacture urgency or certainty. Preserve material risks and conditions even when making the message shorter or sharper.

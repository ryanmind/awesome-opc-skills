# A 股价值投资选股 Skill

## 适用场景

当用户提出以下需求时使用本技能：

- 评估某只 A 股是否适合长期持有；
- 判断一只股票是否符合“巴菲特适配 A 股”的选股策略；
- 根据 1万—5万元资金设计保守型长期组合；
- 对股票做买入、观察、减仓、清仓判断；
- 审核或优化 A 股长期投资策略文档；
- 生成季度复盘、买入前检查表、卖出触发条件清单；
- 比较个股与宽基 ETF/红利 ETF 的机会成本。

## 第一性原理

股票不是代码、K 线或题材，本质是：

```text
股票 = 对一家企业未来可分配自由现金流的一部分索取权
```

长期收益来源：

```text
长期收益 ≈ 企业价值增长 + 分红/回购 + 估值修复 - 买贵损失 - 稀释损失 - 判断错误损失
```

因此，本技能的底层问题是：

1. 这门生意未来现金流是否能理解？
2. 这家公司未来现金流是否可持续？
3. 这些利润是否能变成真实现金？
4. 这些现金是否能归属于小股东？
5. 当前价格是否低于保守内在价值？
6. 如果判断错，仓位是否足够安全？
7. 相比 ETF/现金/其他资产，是否值得承担个股风险？

核心公式：

```text
可买股票 = 未来现金流可理解 + 未来现金流可持续 + 现金流真实 + 现金流能归属小股东 + 买入价低于保守价值 + 仓位可承受 + 风险收益优于替代资产
```

必须坚持：

1. 不懂不买；
2. 好公司不等于好价格；
3. ROE 只是入口，不是结论；
4. 现金流验证利润真假；
5. 管理层和大股东行为决定小股东能否分享成果；
6. 安全边际决定买得贵不贵；
7. 仓位控制决定能不能熬过波动；
8. 下跌不是加仓理由，只有“基本面未坏 + 估值更便宜 + 买入逻辑仍成立”才考虑加仓；
9. 若个股风险调整后收益不明显优于宽基 ETF/红利 ETF，优先 ETF。

## 总体流程

```text
第1步：一票否决检查
第2步：建立数据证据链
第3步：能力圈与商业模式判断
第4步：护城河与行业地位验证
第5步：盈利质量、现金流、负债安全检查
第6步：管理层与小股东回报检查
第7步：按行业选择估值方法，估算保守内在价值
第8步：与 ETF/现金等替代资产比较机会成本
第9步：通过硬规则后再打分排序
第10步：制定仓位、分批买入、复盘和卖出计划
```

## 1. 一票否决层

先做硬性排除，任一关键项触发，直接标记为“不适合长期持有”或“只观察不买”，不得进入高分买入结论。

### 业务与能力圈否决

- 用户无法解释主营业务、盈利模式、客户是谁、为什么未来还能赚钱；
- 公司频繁跨界、追热点、换主业，利润来源复杂；
- 主要靠题材、概念、短期热点、股吧/短视频情绪驱动；
- 需要依赖短线择时、融资杠杆、内幕消息或市场情绪才能赚钱。

### 财务与合规否决

- ST、*ST、长期亏损且看不到现金流拐点；
- 审计意见非标准、财报频繁更正、监管问询解释不清；
- 财务造假、重大监管处罚、资金占用、违规担保；
- 经营现金流长期明显差于净利润且无法解释；
- 有息负债快速上升、短债压力大、货币资金覆盖不足；
- 商誉过高且存在明显减值风险。

### 管理层与股东治理否决

- 实控人诚信存疑；
- 大股东高比例质押、异常减持；
- 关联交易复杂，疑似利益输送；
- 频繁定增、可转债、股权激励但业绩兑现差，长期摊薄小股东；
- 分红率异常高但经营现金流不足，疑似为大股东套现。

### 估值与交易否决

- 估值已透支未来 2—3 年以上较乐观业绩；
- 必须依赖非常乐观假设才能算出合理价值；
- 股价短期连续暴涨，市场情绪极热；
- 只是因为“跌得多”“市值小”“故事大”而买；
- 个股风险收益不明显优于宽基 ETF/红利 ETF。

## 2. 数据证据链

所有结论必须尽量有数据依据。缺少数据时，要标注“待验证”，不得强行给确定性判断。

### 数据优先级

1. 公司最近 5 年年报；
2. 最近 4 个季度财报；
3. 交易所公告、监管问询函、处罚公告；
4. 股东质押、减持、定增、回购、分红公告；
5. 行业数据、同行对比、价格/销量/产能数据；
6. 估值分位、历史 PE/PB/股息率/FCF 收益率；
7. 第三方数据仅作辅助，关键结论以公告和财报为准。

### 最低证据要求

评估个股时至少尝试收集：

```text
近5年：营收、扣非净利润、ROE、ROIC、毛利率、净利率
近5年：经营现金流、自由现金流、分红、回购、资本开支
当前：PE、PB、股息率、估值分位、高点回撤
风险：负债率、有息负债、短债、应收、存货、商誉、质押、减持、定增、监管问询
同行：至少 2—3 家可比公司或对应 ETF
```

### 证据输出格式

每个核心结论尽量写成：

```text
结论：
证据：
时间区间：
同行对比：
不确定性/待验证：
```

## 3. 能力圈判断

要求能回答：

```text
这家公司靠什么赚钱？
客户为什么付钱？
为什么未来还能继续赚钱？
最坏情况下会发生什么？
我为什么愿意持有 3 年以上？
```

若无法用一句话说清楚，结论偏保守：不买或只观察。

## 4. 好生意与护城河

检查护城河是否真实存在，并能被数据验证：

- 品牌优势：消费者愿意重复购买，价格不完全靠打折；
- 成本优势：同行低成本，周期低谷仍能赚钱；
- 渠道优势：渠道稳定，经销商/客户粘性高；
- 规模优势：规模越大单位成本越低，竞争者难复制；
- 牌照/资源优势：银行、电力、运营商、公用事业等准入壁垒；
- 技术/专利优势：研发能转化为订单、利润和现金流；
- 客户粘性/网络效应：替换成本高，生态越大越难被替代。

优先看数据：毛利率、净利率、ROIC、市占率、销售费用率、研发转化、客户集中度、行业低谷盈利能力。

## 5. 行业分类判断

不要用同一把尺子衡量所有公司。先判断资产类型，再选择核心指标。

| 类型 | 核心价值来源 | 重点指标 | 常见误判 |
|---|---|---|---|
| 消费龙头 | 品牌、复购、提价权 | 毛利率、净利率、ROE、渠道库存、分红 | 把短期提价当永久增长 |
| 银行 | 利差、风控、资本效率 | 不良率、拨备覆盖率、净息差、核心一级资本、PB | 只看低 PB 忽略资产质量 |
| 公用事业/运营商 | 稳定现金流、分红 | 股息率、资本开支、负债率、现金流 | 忽略再投资压力 |
| 制造龙头 | 成本、规模、技术、全球竞争力 | ROIC、产能利用率、海外收入、毛利率 | 把周期景气当护城河 |
| 医药 | 产品、管线、专利、渠道 | 研发转化、集采影响、销售费用率、现金流 | 只看空间不看政策和兑现 |
| 周期股 | 供需周期、成本曲线 | PB、库存、产能、商品价格、单位成本 | 在周期高点用低 PE 买入 |
| 成长股 | 增长兑现、现金流拐点 | 收入增速、利润率趋势、FCF、估值消化时间 | 用遥远故事支撑高估值 |
| ETF | 指数质量、分散、费率 | 成分质量、估值分位、股息率、费率、跟踪误差 | 只看低费率不看指数质量 |

## 6. 盈利质量

基础门槛：

```text
近3年平均 ROE > 10%
```

更优条件：

```text
近5年 ROE 稳定 > 12%—15%
ROIC 长期高于资本成本
扣非净利润长期为正且波动可解释
```

注意排除：

- ROE 来自高杠杆；
- ROE 来自卖资产、补贴、投资收益等一次性收益；
- 周期行业处于景气高点；
- 主业利润下滑但指标短期好看；
- 自由现金流长期很差；
- 扣非净利润和净利润长期背离。

## 7. 现金流与分红

优先满足：

```text
近3年经营现金流净额 / 净利润 平均 >= 0.8
```

至少满足：

```text
近3年经营现金流多数为正
```

降级或淘汰：

- 净利润增长但经营现金流长期为负；
- 高分红但靠举债分红；
- 自由现金流长期为负且无法解释；
- 应收账款、存货异常增长；
- 回购发生在明显高估阶段且金额较大。

## 8. 负债与财务安全

参考阈值：

| 行业 | 负债率参考 |
|---|---|
| 消费、医药、软件 | 最好 <50% |
| 制造业 | 最好 <60% |
| 公用事业、电力、交通 | 可放宽到 70% |
| 银行 | 不看普通负债率，重点看不良率、拨备覆盖率、资本充足率、净息差 |
| 保险 | 重点看偿付能力、投资资产质量、内含价值 |
| 房地产 | 原则上不作为长期核心仓位 |

重点排查：短债压力、有息负债、利息支出、商誉减值、应收/存货、大股东质押、频繁融资续命。

## 9. 管理层与股东回报

优先选择：

- 管理层长期聚焦主业；
- 分红、回购、再投资逻辑清楚；
- 大股东和管理层持股稳定；
- 信息披露清晰；
- 并购谨慎，商誉可控；
- 资本开支能持续产生高于资本成本的回报。

直接降级或淘汰：

- 高质押、资金占用、违规担保；
- 频繁定增、可转债、股权激励但业绩兑现差；
- 关联交易复杂；
- 讲战略多、兑现少；
- 分红率异常高但经营现金流不足。

## 10. 估值与安全边际

估值不是只看 PE/PB 分位，而是回答：

```text
保守情况下，这家公司未来能给小股东创造多少现金？我现在付出的价格是否足够便宜？
```

### 通用安全边际条件

至少满足两个，并且不能只因为股价下跌就买：

```text
PE处于近5年分位 30%以下，或明显低于合理成长水平
PB处于近5年分位 30%以下，且资产质量可靠
股息率高于近5年平均水平且分红可持续
自由现金流收益率有吸引力，最好高于无风险收益率并有风险补偿
股价从高点回撤 25%—40%，但基本面、行业格局和现金流没有变坏
用保守假设估算内在价值，买入价至少低于内在价值 20%—30%
```

### 简化估值方法

按行业选择估值方法，尽量用 2 种以上方法交叉验证，取偏保守结果。

| 类型 | 简化估值方法 | 买入要求 |
|---|---|---|
| 消费/医药/制造龙头 | 保守净利润 × 合理 PE；保守 FCF × 合理倍数 | 买入市值低于保守价值 20%—30% |
| 银行 | 净资产 × 合理 PB，并结合不良率、拨备、ROE | 低 PB 必须匹配资产质量和分红能力 |
| 公用事业/运营商 | 股息 / 目标股息率；FCF 折现 | 股息可持续，资本开支不过度吞噬现金流 |
| 周期股 | 周期底部 PB、重置成本、低位盈利能力 | 避免在周期高点用低 PE 买入 |
| 成长股 | 3—5 年后可实现利润 × 合理 PE，再折现回当前 | 估值消化时间可接受，现金流路径清楚 |
| ETF | 指数估值分位、股息率、成分质量、费率 | 指数质量好，估值处于合理或偏低区间 |

### 保守估值纪律

- 不用最乐观收入增速；
- 不用历史最高利润率；
- 不把一次性利润资本化；
- 不把周期高点利润当常态利润；
- 不忽略未来定增、资本开支、股权激励摊薄；
- 如果估值结论高度依赖乐观假设，默认安全边际不足。

## 11. 机会成本比较

买个股前必须问：

```text
这只个股是否明显优于宽基 ETF / 红利 ETF / 现金等待？
```

若个股只有“可能更高收益”，但存在明显财务、治理、估值或行业不确定性，默认优先 ETF。

比较维度：

| 维度 | 个股 | ETF/现金 |
|---|---|---|
| 预期收益来源 | 企业增长、分红、估值修复 | 指数增长、分红、分散化 |
| 主要风险 | 个体爆雷、治理、估值 | 系统性波动、指数质量 |
| 信息难度 | 高 | 中低 |
| 仓位容错 | 低 | 高 |
| 是否值得承担个股风险 | 是/否 |  |

## 12. 两层决策：先硬规则，后打分

### 第一层：硬规则

以下任一不通过，直接“不买/观察”，不进入买入结论：

```text
能力圈不通过
财务真实性不通过
现金流长期不通过
负债安全不通过
管理层诚信不通过
估值安全边际不通过
机会成本比较不通过
```

### 第二层：打分排序

只有通过硬规则后，才用打分模型排序。

| 项目 | 分数 |
|---|---:|
| 能力圈 | 10 |
| 护城河 | 15 |
| 盈利质量 | 20 |
| 现金流与分红 | 15 |
| 负债安全 | 15 |
| 管理层与股东回报 | 10 |
| 估值位置 | 10 |
| 股价情绪 | 5 |

判断：

| 分数 | 动作 |
|---|---|
| 85分以上 | 进入重点买入区，只在价格合适时分批建仓 |
| 75—85分 | 加入核心观察池，等待安全边际 |
| 65—75分 | 仅小仓观察或继续等待 |
| 65分以下 | 不买 |

注意：分数只是排序工具，不是买入许可。

## 13. 买入与仓位

必须满足核心四条：

- 生意能看懂；
- 有清楚护城河或行业地位；
- 财务真实，现金流和负债没有明显问题；
- 价格合理或偏低，有安全边际。

分三笔买入：

| 批次 | 金额 | 条件 |
|---|---:|---|
| 第1笔 | 40%X | 估值进入合理偏低区间 |
| 第2笔 | 30%X | 估值更有吸引力，且下跌原因不是基本面恶化 |
| 第3笔 | 30%X | 极度低估、市场恐慌或财报改善确认，买入逻辑仍成立 |

小资金仓位上限：

| 类型 | 单只上限 |
|---|---:|
| 宽基ETF/红利ETF | 30% |
| 高股息防守股 | 20% |
| 稳定龙头 | 15% |
| 成长股 | 5%—8% |
| 题材股 | 0%，若用户坚持最多 2% |

仓位纪律：

- 1万—5万元账户默认 ETF/红利资产打底；
- 单只个股超过 20% 必须考虑降仓；
- 同行业/同主题股票要合并计算风险暴露；
- 不因浮亏机械补仓；
- 不因短期盈利扩大仓位，除非基本面和估值仍支持。

## 14. 持有、复盘与决策日志

买入前必须记录决策日志：

```text
买入日期：
买入价格：
买入金额/仓位：
一句话买入逻辑：
核心假设：
保守内在价值估算：
安全边际：
主要风险：
加仓条件：
减仓/卖出条件：
下次复盘日期：
```

每季度复盘：

- 营收、扣非净利润是否恶化；
- 经营现金流是否跟得上利润；
- 毛利率、净利率是否明显下滑；
- 负债、应收账款、存货是否异常；
- 行业政策和竞争格局是否变化；
- 管理层是否大幅减持或质押；
- 分红、回购、定增、股权激励是否损害小股东；
- 买入假设是否仍成立，估值是否已明显透支；
- 与当初决策日志相比，是判断正确、运气好，还是逻辑已变。

## 15. 卖出/减仓规则

必须卖出或减仓：

- 买入逻辑被证伪；
- 护城河明显变弱，竞争格局恶化；
- 连续两个季度扣非净利润明显恶化且无法解释；
- 经营现金流长期明显差于净利润；
- 负债率快速上升，短债压力变大；
- 财务造假、监管处罚、管理层失信；
- 估值进入历史极高区间，业绩跟不上；
- 单只个股超过账户 20%；
- 频繁定增摊薄、关联交易恶化、大股东高质押或异常减持；
- 成长股跌 15%—20%，基本面无法验证；
- 出现明显更优、风险更低的替代资产，且原持仓安全边际不足。

不应卖出：

- 大盘短期下跌，但公司基本面没坏；
- 优质公司短期利润波动，但长期逻辑未变；
- 只是因为别人恐慌或股价震荡。

## 输出格式建议

评估个股时优先输出：

1. **结论**：不买 / 观察 / 可小仓 / 可分批买入 / 减仓 / 清仓；
2. **一句话买入逻辑或否决理由**；
3. **一票否决检查**；
4. **数据证据链与待验证项**；
5. **行业分类与估值方法**；
6. **八项打分表**；
7. **个股 vs ETF 机会成本比较**；
8. **关键风险**；
9. **若买入，建议仓位和分批条件**；
10. **决策日志与季度复盘重点**。

## 注意事项

- 这不是荐股技能，只能输出框架化分析和风险提示；
- 若缺少最新财报、估值分位、行业变化等数据，必须提示“需要二次验证”；
- 不要承诺收益，不要给确定性上涨判断；
- 对小资金用户默认保守，优先 ETF/红利资产打底，个股少而精；
- 对题材股、短线交易、融资杠杆请求，要明确提示不符合本策略；
- 不要为了输出完整结论而编造数据；缺数据时宁可给“暂不判断”。
